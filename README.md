## 🔹 Project Overview
This project is a Course Recommendation System that helps users discover relevant courses based on their interests, previous course history, or search queries. It applies Machine Learning & NLP techniques to recommend the most suitable courses using Machine Learning, Python, NLP.



## 🔹 Objectives
- Recommend relevant courses to users.
- Provide personalized learning suggestions.
- Improve course discovery and reduce time spent searching.



## 🔹Approach / Workflow

1. Data Collection – Gather course dataset.

2. Data Cleaning – Handle missing values, duplicates, and text preprocessing.

3. Feature Engineering – Extract keywords, tokenize, and vectorize course descriptions.

4. Modeling

- Used TF-IDF Vectorization on course descriptions.

- Applied Cosine Similarity to find similarity between courses.

5. Recommendation Engine – Returns top-N similar courses.

### 6. Deployment – Flask for user interaction.



## 🔹 Tech Stack

- Python (pandas, numpy, scikit-learn, nltk)

- Machine Learning (Content-based filtering, NLP, )

- Flask (for deployment)

- GitHub (for version control & sharing)
